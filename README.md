BodegaElChavo

Proyecto básico en Java que simula el funcionamiento de una bodega. Incluye registro de empleados, compras, productos, categorías y ventas. Se usan conceptos de Programación Orientada a Objetos.

Contenido del proyecto

- Registro de empleados por consola  
- Registro de compras (con proveedor, productos y total)  
- Categorías y productos  
- Registro de ventas  
- Guardado de ventas en archivo de texto  
- Interfaz gráfica simple con Swing (formularios internos)

Tecnologías usadas

- Java  
- Swing  
- NetBeans
